# Helio / Daylight Atlas

Original React / TypeScript / Three.js sunlight planner. Early visual checkpoint; numerical planner and QA are in progress.

`npm ci`, `npm run dev`, `npm run build`. Build goes to `docs/` for free GitHub Pages.

No weather, real terrain, location access, accounts, API keys or telemetry. The world is an original artistic scene. Solar calculations run locally using pinned SunCalc 2.1.0. Reference videos were inspected by the parent and visual reviewer, not on this Windows execution environment.
